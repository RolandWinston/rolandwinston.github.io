# Roland 作品集

个人作品集静态展示站，包含游戏、AI应用、工具链、VR、金融自动化及社群销售案例。

目标地址：https://rolandwinston.github.io/

发布：在仓库 Settings → Pages 中选择 Deploy from a branch、main 分支、根目录。`.nojekyll` 让现有静态文件直接发布。

试玩和大型下载沿用现有公开资源地址；这个仓库保存展示页面、图片、音乐和案例文档。素材署名及许可见 asset-credits.html 与对应资源文件。

更新文本和链接后，将变更提交至 main；提交前检查首页、项目页、试玩入口及手机布局。
